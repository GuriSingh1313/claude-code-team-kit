# Examples

- `vibe-coded-app/`: a small Express prototype of the kind AI app builders produce. **Deliberately insecure demo fixture**: the committed `.env` and the "secrets" in the code are fake values that exist only so the readiness audit has something realistic to find.
- `fixes/`: the changes a senior engineer makes after installing the kit (tests, validation, auth on DELETE, env-based secrets, lint, CI, CLAUDE.md). `package-lock.json` here is a stub fixture.
- `reports/`: audit reports for each stage, regenerated by `npm run demo`.
